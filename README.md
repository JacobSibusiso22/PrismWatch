# PrismWatch

## Overview

PrismWatch is a centralized RPA Monitoring & Intelligence Platform designed to provide real-time visibility into automation operations.

The solution consolidates queue metrics, resource health, exception data, SLA monitoring, reporting, alerting, and operational intelligence into a single dashboard.

## Features

- Queue Monitoring
- Resource Monitoring
- Exception Analytics
- SLA Tracking
- Automated Reporting
- Health Checks
- Operational Dashboards
- AI-Powered Insights

## Technology Stack

- Python
- Streamlit
- SQL Server
- Blue Prism
- Power Automate
